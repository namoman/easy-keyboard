# 이지키보드 (EasyKeyboard) UI/UX 디자인 명세서 (`UI_UX_SPEC.md`)

> 본 문서는 `easy_keyboard_spec.md` (아키텍처 및 백엔드/보안 명세)와 짝을 이루는 **프론트엔드 UI/UX 전용 명세서**입니다. 기존 명세에 정의된 `src/lib/components/` 구조(`KeypadCanvas.svelte`, `SnippetEditor.svelte`, `HardwareTab.svelte`, `OsdOverlay.svelte`)를 기준으로 작성되었습니다.

---

## 1. 시각 디자인 컨셉 (Visual Direction)

- **Tactile Hardware Utility (택타일 하드웨어 감성):** 과장된 게이밍 RGB 그라데이션이나 번잡한 입체 효과를 배제하고, `1px`의 정교한 보더와 매트한 다크 서피스(`#0B0C0E`)로 책상 위 물리 매크로 패드와 일체감을 주는 모던 유틸리티 스타일(Linear, Raycast, Teenage Engineering 레퍼런스)을 지향합니다.
- **Zero-Scroll Single Viewport:** 메인 설정 창(`960 × 640 px`) 안에서 스크롤 없이 **좌측 물리 키패드 미러링 캔버스**와 **우측 편집 인스펙터**를 한눈에 보며 모든 매핑을 끝낼 수 있도록 고정 2단 그리드로 설계합니다 ([MINIKeyboardWeb](https://github.com/hobbyworker/MINIKeyboardWeb)).

### 3.1 상단 헤더 바 (Top Bar — 높이 `52px`)
- **좌측 (연결 상태 & 무선 프로필 스위치):**
  - USB 연결 시 초록색 도트(`● USB 연결됨`), 무선 사용 중일 때는 파란색 도트(`● 스니펫 데몬 활성`).
  - 트리거 프로필 드롭다운: `[동글/유선 모드 (F13~F24)]` vs `[블루투스 호환 모드 (조합키)]` 전환 스위치.
- **중앙 (레이어 탭):** `Layer 1`, `Layer 2`, `Layer 3` 세그먼트 버튼 (`Alt+1/2/3` 단축키 지원).
- **우측 (글로벌 컨트롤):**
  - `[ ↻回転 ]`: 책상 위 패드 배치 방향에 맞춰 캔버스를 `0° / 90° / 180° / 270°` 회전 ([MINIKeyboardWeb](https://github.com/hobbyworker/MINIKeyboardWeb)).
  - `[ 👁 OSD ]`: 반투명 오버레이 창 켜기/끄기 토글.
  - `[ 기기에 동기화 (Ctrl+S) ]`: 미저장 변경 사항이 있을 때만 Amber(`#F59E0B`) 배경으로 활성화되고 저장 시 Read-back 검증 애니메이션 표시.

## 4. 컴포넌트별 상세 UI/UX 명세

### 4.1 `KeypadCanvas.svelte` (좌측 패널 — 너비 `420px`)
실물 `514C:8850`의 3노브 + 4×4 키 그리드를 렌더링하고 선택·드래그 상태를 관리합니다.

- **노브 유닛 (`KnobUnit` × 3개):**
  - 원형 다이얼(`64 × 64 px`) 아래에 **좌회전(`[↺]`) · 푸시(`[●]`) · 우회전(`[↻]`)** 3개의 캡슐형 서브 버튼이 배치되어, 다이얼의 어느 동작을 편집할지 직관적으로 클릭할 수 있습니다.
- **키캡 카드 (`KeycapTile` × 16개, 각 `78 × 78 px`, `rounded-xl`):**
  - **내부 레이아웃:**
    - **상단 행:** 좌측에 슬롯 번호(`01`~`16`), 우측에 모드 상태 점(Amber = 스니펫, Cyan = 하드웨어 매핑, Rose 자물쇠 = 민감 스니펫, 없음 = 빈 키).
    - **중앙 영역:** 사용자 지정 라벨 (최대 2줄, 한글 6~8자 내외 가독성 최적화, 말줄임표 처리).
    - **하단 행:** 할당된 키코드(`F13`, `Ctrl+C`)를 `10px` 모노스페이스 폰트로 작게 표기.
  - **키별 RGB 언더글로우:** 키캡 카드 하단 보더(`border-b-2`)에 해당 키의 LED 색상을 표시해 별도 탭에 가지 않고도 조명 구성을 확인합니다.
  - **인터랙션:**
    - **클릭:** 우측 인스펙터에 해당 슬롯 로드 (`border-amber-500 ring-2 ring-amber-500/20`).
    - **드래그 앤 드롭:** 키캡을 다른 키캡으로 끌어다 놓으면 두 슬롯의 데이터(스니펫+하드웨어 매핑)가 부드러운 트랜지션과 함께 즉시 교체(Swap)됩니다.
    - **실시간 입력 피드백:** 실제 물리 패드에서 키를 누르면 화면의 해당 키캡 카드가 `scale(0.96)`으로 눌리며 테두리가 반짝입니다.

### 4.2 `SnippetEditor.svelte` (우측 인스펙터 — 탭 1: 텍스트 스니펫)
원하는 텍스트를 가장 빠르고 쾌적하게 붙여넣고 관리하는 핵심 화면입니다.

- **빠른 붙여넣기 빈 상태 (Empty State):**
  - 비어 있는 키를 선택하면 에디터 중앙에 큰 점선 박스로 **`[ 📋 클릭하여 현재 클립보드 텍스트 바로 등록 (Ctrl+V) ]`** 버튼을 띄워 원클릭으로 등록할 수 있게 합니다.
- **라벨 자동 완성:**
  - 사용자가 본문만 붙여넣고 라벨 칸을 비워두면, 본문 첫 줄의 앞 8글자(공백 제외)를 플레이스홀더 및 기본 라벨로 자동 추출합니다.
- **동적 변수 삽입 칩 바:**
  - 텍스트 영역 바로 위에 `[ + {{date}} (오늘 날짜) ]`, `[ + {{time}} (현재 시각) ]`, `[ + {{clipboard}} (복사된 내용) ]` 칩을 배치해, 클릭 시 커서 위치에 하이라이트된 태그 형태로 삽입합니다.
- **하단 토글 옵션:**
  - **민감 텍스트 보호 (`Secret`):** 켜면 에디터 텍스트에 블러(`blur-sm`, 마우스 호버 시에만 노출)가 걸리고 OSD에는 라벨만 표시됩니다.
  - **붙여넣기 후 동작:** `[없음]` / `[자동 Enter ↵]` / `[자동 Tab ⇥]` 중 선택.

### 4.3 `HardwareTab.svelte` (우측 인스펙터 — 탭 2: 단축키/마우스/RGB)
패드 온보드 메모리에 직접 기록되는 하드웨어 기능 설정 화면입니다.

- **키 시퀀스 타임라인 에디터 (최대 18타):**
  - 기존의 답답한 텍스트 입력 대신 `[ Ctrl ] + [ C ] ──( ⏱ 50ms )──> [ Alt ] + [ Tab ]` 형태의 **수평 블록 타임라인**으로 시각화합니다.
  - 블록 사이의 `⏱ 50ms` 알약(Pill) 배지를 클릭하거나 마우스 휠을 굴리면 `0ms`부터 `6000ms`까지 키별 딜레이가 즉시 조절됩니다 ([Macrocli](https://github.com/USERNAME-STOCK/Macrocli)).
- **마우스 & 노브 제어 카드:**
  - **스크롤 배속 슬라이더:** `1x (기본)` ~ `5x (고속)` 단계별 슬라이더로 노브 회전 시 스크롤 속도를 직관적으로 설정합니다 ([ch57x-keyboard-tool Issue #153](https://github.com/kriomant/ch57x-keyboard-tool/issues/153)).
  - **2D 조이스틱 패드 UI:** 마우스 X/Y 커서 이동량을 숫자 입력뿐만 아니라 십자형 미니 패드 드래그로도 설정할 수 있게 구성합니다.
- **LED 컬러 피커 바:**
  - 인스펙터 하단에 항상 고정된 7색 스와치 서클(`Red`, `Green`, `Blue`, `Yellow`, `Cyan`, `Purple`, `White`, `Off`)을 두어, 탭을 이동하지 않고도 현재 키의 LED 색상을 원클릭으로 바꿀 수 있게 합니다.

### 4.4 `OsdOverlay.svelte` (반투명 치트시트 위젯 — `260 × 310 px`)
작업 중 화면 구석에 띄워두는 두 번째 Tauri 윈도우(`osd-window`)의 UI 규격입니다 ([Macrocli](https://github.com/USERNAME-STOCK/Macrocli)).

```text
+---------------------------------------+
| [L1] 이지키보드 OSD      [👻] [━] [×] | <- 24px 헤더 (드래그 영역)
+---------------------------------------+
|  (N1: 줌)   (N2: 스크롤3x)  (N3: 볼륨)| <- 32px 노브 요약 바
+---------+---------+---------+---------+
| 01 복사 | 02 붙여 | 03 캡처 | 04 검색 |
+---------+---------+---------+---------+
| 05 결재 | 06 준공 | 07 메일 | 08 🔒   | <- 4x4 컴팩트 그리드
+---------+---------+---------+---------+
| 09 코드 | 10 빌드 | 11 터미 | 12 커밋 |
+---------+---------+---------+---------+
| 13      | 14      | 15      | 16 레이어|
+---------+---------+---------+---------+
```

- **글래스모피즘 스타일:** `bg-[#0B0C0E]/80 backdrop-blur-md border border-white/10 rounded-2xl shadow-2xl`을 적용해 어떤 배경 위에서도 글자가 선명하게 읽히도록 합니다.
- **실시간 입력 펄스 (Pulse Feedback):** 물리 패드에서 키를 누르면 OSD의 해당 칸이 `150ms` 동안 Amber 빛으로 차오르며, 상단 바에 `"✓ [05 결재] 붙여넣기 완료"` 마이크로 토스트가 1초간 표시됩니다.
- **인라인 우클릭 팝오버:** OSD 칸을 우클릭하면 메인 창을 띄우지 않고도 그 자리에서 라벨 이름과 스니펫 텍스트를 바로 고칠 수 있는 미니 편집 풍선이 뜹니다 ([Macrocli](https://github.com/USERNAME-STOCK/Macrocli)).
- **자동 회피 / 유령 모드 (`👻 Ghost Mode`):** 활성화 시 마우스 커서가 OSD 위를 지나갈 때 투명도가 `15%`로 낮아지며 클릭이 뒤쪽 작업 창으로 그대로 통과(`set_ignore_cursor_events(true)`)됩니다.

## 5. 주요 마이크로 인터랙션 및 단축키 규격

| 동작 | 단축키 / 트리거 | UI 피드백 |
| :--- | :--- | :--- |
| **빠른 스니펫 붙여넣기 등록** | 키캡 선택 후 `Ctrl + V` | 우측 에디터에 클립보드 내용 즉시 입력 + 첫 줄 라벨 자동 추출 |
| **기기에 저장 및 검증** | `Ctrl + S` | 상단 프로그레스 바 진행 → Read-back 대조 → 초록색 체크 배지 점등 |
| **레이어 빠른 전환** | `Alt + 1`, `Alt + 2`, `Alt + 3` | 캔버스 전체 키캡이 슬라이드 페이드(`120ms`)로 전환 |
| **OSD 오버레이 토글** | `Ctrl + Shift + O` (글로벌) | 작업 중 언제든 OSD 위젯 표시 / 숨김 |
| **OSD 유령 모드(클릭 통과) 토글**| `Ctrl + Shift + G` (글로벌) | OSD 테두리가 점선으로 바뀌며 마우스 클릭 통과 활성화 |
